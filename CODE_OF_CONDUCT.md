# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, discrimination and personal attacks are not tolerated in issues, pull requests, discussions or any other project space.

Report unacceptable behavior privately to the maintainers (see the contact in the repository profile). All reports are reviewed and handled confidentially.
